## 2. はじめに（Introduction、各 2-3 ページ）

### Why this handbook exists

> 日本に来る人は、最初の 3 ヶ月で 30-50 件の手続きと 100 単語以上の役所用語に直面する。Google 翻訳で乗り切ろうとすると 60% は乗り切れるが、残り 40% で「住民票って何？」「マイナンバーって何？」「分別って何？」と詰まる。本書は、その 40% を **一般情報レベル**で先回りする。

### Who this is for

- 日本留学を始める学生（Persona A: LEARNER）
- Working Holiday で来日する旅行者（Persona B: TRAVELER）
- 就職・配偶者ビザで在住開始する人（Persona C: RESIDENT）
- 子連れで来日・在住する家族（Persona D: FAMILY、2026-05-05 リブランドで追加）

### What this is NOT

- 個別案件のアドバイス
- 書類代筆サービス
- 法律相談
- AI チャット連動の自動回答

### How to use this handbook

- 章ごとに独立、必要な章だけ読んでよい
- 各章末に「自治体公式リンク」「関連語彙 10 語」を掲載
- Appendix A の自治体公式リンク集が最終情報源
- 個別ケースは Appendix C の専門家リストに相談

## 3. Chapter 1: 来日前準備（Before You Arrive、5-7 ページ）

### 1.1 概要（200 字）

来日前に押さえる 5 つの手続き: ① 在留資格 / VISA 種別の概念整理、② 住居先の決定（最低限の住所がないと住民票が作れない）、③ 銀行口座開設前提（多くは在留カードと住所証明が必要）、④ クレジットカード / 携帯電話 SIM の事前検討、⑤ 印鑑（実印）の作成。

### 1.2 在留資格 一般手続き（流れ図）

> ⚠️ **個別の VISA 種別判定 / 申請書代筆は本書の対象外**。具体例は架空名による一般フロー説明のみ。

主要 4 種の在留資格 + 一般フロー（短期 / 留学 / 就労 / 配偶者）。

### 1.3 架空名による記入例（般化）

```
氏名: 山田 太郎 (架空名、Yamada Taro)
```

なぜ日本ではサインではなく印鑑を求められる場面が多いか、印鑑とサインの法的扱いの違い、実印・銀行印・認印の 3 種類。

## 4. Chapter 2: 着任直後の手続き（First Week in Japan、5-7 ページ）

### 2.1 概要（200 字）

空港着 → 7 日以内にやることは 4 つ: ① 在留カード受取、② 住居先確定、③ 14 日以内に住民票届出（市役所/区役所）、④ 銀行口座開設の事前リサーチ。SIM カード（携帯電話）は空港 or 翌日でも可。

### 2.2 空港での手続き

成田 / 羽田 / 関空 / 中部の 4 主要空港の入国審査 → 在留カード即日受領フロー。

### 2.3 SIM カード選択肢（一般情報）

| サービス | 月額目安 | 契約条件 |
|---|---|---|
| 大手キャリア（docomo / au / SoftBank） | ¥4,000-7,000 | 在留カード + 銀行口座 or クレカ |
| MVNO（IIJmio / mineo / 楽天モバイル等） | ¥1,000-3,000 | 在留カード必須、契約者 13 歳以上 |
| Prepaid SIM（観光客向け） | ¥3,000-5,000 / 月 | パスポートのみ |

### 2.4 銀行口座開設（一般フロー）

主要 3 銀行（ゆうちょ / みずほ / 三菱 UFJ）の開設条件 + 必要書類リスト + よくある拒絶理由（在留 6 ヶ月以下、住民票なし、就労ビザ未受領 等）。

## 5. Chapter 3: 市役所・区役所手続き（Municipal Office、6-8 ページ）

### 3.1 概要（200 字）

着任 14 日以内に最重要: ① 住民票届出（住所登録）、② マイナンバーカード申請（必須ではないが強く推奨）、③ 国民健康保険加入（就労ビザの会社加入なら社会保険）、④ 国民年金（20 歳以上の在住者）。すべて住んでいる市/区の役所窓口で完結。

### 3.2 住民票（住民登録、Resident Registration）

- 14 日以内届出義務（外国人住民は 90 日超滞在者）
- 必要書類: 在留カード / パスポート / 賃貸契約書 or 住居証明
- 受領できるもの: 住民票記載事項証明書（後の銀行口座 / SIM 契約に使う）

### 3.3 マイナンバーカード（My Number Card）

- 住民票登録後 2-4 週間で通知カード送付（紙）
- 申請方法: スマホ / 郵送 / 役所窓口
- 機能: 銀行口座連携、e-Tax 確定申告、健康保険証連携（2024 年以降）
- **注意**: 取得は任意だが、確定申告 / e-Tax / 海外送金時に強く推奨

### 3.4 国民健康保険 / 国民年金

- 会社員 = 社会保険（会社経由）
- 自営業 / 留学生 / 無職 = 国民健康保険（市役所）
- 国民年金は 20 歳-60 歳必須（学生免除制度あり）

### 3.5 架空名フローチャート

```
[山田太郎が 5/1 着任 → 5/15 期限]
  Day 1-3: 賃貸契約 + 住居確定
  Day 4-5: 区役所で住民票届出（在留カード + 賃貸契約書持参）
  Day 6-10: マイナンバー通知カード受領待ち
  Day 7-14: 国民健康保険 + 国民年金加入手続き（同じ区役所窓口）
```

## 6. Chapter 4: 日常生活ルール（Daily Life Rules、6-8 ページ）

### 4.1 概要

ゴミ分別 / 自治会 / 騒音 / 喫煙 / 自動車運転 等の「見えないルール」。違反しても警察沙汰にはならないが、近隣トラブルの原因 No.1。

### 4.2 ゴミ分別（市町村別の差を強調）

- 燃えるゴミ / 燃えないゴミ / 資源ゴミ / 大型ゴミ の 4 系統
- 出す日 + 出す時間 + 指定袋 が市町村ごとに違う
- 違反すると「収集してくれない」（罰金ではない）→ 自宅前にゴミが残る

### 4.3 自治会・町内会

- 入会任意、月会費 ¥500-2,000
- 入らないと「自治会限定の防災情報」「子供会」等にアクセスできない
- 入会方法: 大家経由 or 直接町内会長に連絡

### 4.4 騒音 / マナー（一般情報）

- 22:00-7:00 は静音時間
- 集合住宅で楽器演奏は管理規約による
- 自転車 vs 歩道 vs 車道 のルール

### 4.5 喫煙

- 屋内全面禁煙（法律 2020-04-01）
- 路上喫煙禁止区域（東京 23 区中心部、京都市内等）
- 喫煙所マップアプリ紹介

### 4.6 自治体公式リンク + 語彙 10 語

### 4.7 子連れ家族 TIPS（2026-05-05 リブランドで追加）

- **保育園・幼稚園**: 認可 / 認可外の違い、入園申し込みの市役所窓口
- **小児科探し**: 「外国語対応 小児科」検索キーワード、夜間救急体制
- **公園・遊び場**: 子連れ向け公園マップ、屋内遊び場の地域差
- **保護者ネットワーク**: 多文化家庭向けコミュニティ（FB / Discord グループ）

## 8. Chapter 6: 緊急時の対応（Emergency、4-6 ページ）

### 6.1 概要

病気 / 自然災害 / 犯罪被害 / 火災 / 交通事故 等の緊急番号 + 多言語サポート窓口。

### 6.2 緊急番号

- 119: 救急 / 火災
- 110: 警察
- 多言語対応: 119 は同時通訳サービス（英・中・韓・西・葡 5 言語）

### 6.3 病気時のフロー

- 軽症: かかりつけ医 / 24 時間救急電話相談（市町村サービス）
- 中等症: 救急外来（事前電話推奨）
- 重症: 119 で救急車

### 6.4 自然災害（地震・台風・大雨）

- 緊急速報メール（Jアラート）の言語設定
- 避難所マップアプリ
- 帰宅困難者支援ステーション
- ハザードマップ確認

### 6.5 犯罪被害

- 警察への届出（在留資格に影響しない）
- 被害者支援窓口
