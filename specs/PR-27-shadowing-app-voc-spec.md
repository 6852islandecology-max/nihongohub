# PR-27 シャドーイング統合アプリ VOC + スペック雛形

- **作成**: 2026-05-14
- **起点**: 日本語学習者インタビュー（オーナー実施）
- **ステータス**: ideation（要 PR 起票判断）
- **関連**: PR-15 Free Trial、PR-25 Japan Life Quiz、PR-26 Hospitality Phrase Pack（音声系資産との接続候補）

---

## 1. ユーザーの声（原文要約）

> 字幕チューブアプリ（字幕付き動画を低速再生できるツール）と HSpeakRec（録音アプリ）を**1 つにまとめたもの**が欲しい。シャドーイング練習が目的。

- ジョブ（JTBD）: 「ネイティブの発話をマネる練習を、字幕付き低速再生 → 自分の声を録音 → 聞き比べ、を 1 画面で完結させたい」
- 既存ペイン: アプリ 2 つを行き来する手間、字幕とのタイミング合わせ、録音物の整理

## 2. 既存リファレンス

| 既存アプリ | 役割 | 強み | 弱み |
|---|---|---|---|
| 字幕チューブ系（例: LingoTube、Language Reactor 等） | YouTube 動画 + 字幕 + 低速再生 + 単語タップ辞書 | 字幕同期・低速再生・辞書 | 録音機能なし／自分の声と比較不可 |
| HSpeakRec | 音声録音 + 再生比較 | 録音波形・区間比較 | 動画/字幕は別アプリ |

## 3. 統合アプリ MVP 機能候補

**コア（必須）**
1. YouTube 動画再生 + 字幕同期表示（日本語 + 学習者母語の二段字幕）
2. 速度コントロール（0.5x / 0.7x / 0.85x / 1.0x、字幕は同速）
3. AB ループ（字幕 1 文単位／任意区間）
4. シャドーイング録音（区間に紐付け、複数テイク保存）
5. オリジナル音声 vs 録音 並列再生（左右切替 or オーバーレイ）

**Nice-to-have（v2 以降）**
- 音素レベルの発音スコア（Whisper / Azure Speech 等）
- 録音ログのカレンダー可視化（連続日数・累計分）
- NihongoHub 既存コンテンツ（47 都道府県、Phrase Pack、Quiz）の音声教材を埋め込み素材として供給

## 4. NihongoHub プロダクト戦略との接続

- **収益モデル整合**: Tofugu × Trip101 ハイブリッドの「Tofugu 軸（単発 AI クイズサブスク）」に、シャドーイング学習を**サブスク同梱機能**として配置できる可能性
- **アフィリ動線**: 動画素材の出典として YouTube 公式チャンネル（NHK ニュース、旅番組）を案内 → Booking/Klook 旅行アフィリへ自然導線
- **Free Trial（PR-15）との合流**: シャドーイング 3 回無料 → メール登録 → サブスク誘導
- **生活ハンドブック（PR-12）との合流**: 役所/病院フレーズの読み上げ → ユーザー復唱 → 録音蓄積

## 5. 技術スタック候補（暫定）

- フロント: Next.js + Plyr or Video.js + YouTube IFrame API
- 字幕: youtube-transcript API or 自家字幕 JSON（PR-26 風）
- 録音: MediaRecorder API（Web）、後に PWA で iOS/Android 対応
- 音声比較: WaveSurfer.js（波形）→ v2 で Whisper API
- バックエンド: 既存 Supabase（ユーザー認証 + 録音メタデータ）

注: YouTube 規約上、動画の再ホストや音声抽出は不可。**プレイヤー埋め込み + 字幕レイヤー + 別レイヤー録音**で実装する前提。

## 6. リスク・確認事項

1. **YouTube IFrame API の低速再生制約**: 0.25/0.5/0.75/1.0/1.25/1.5/2.0 のみ。0.7x 等は不可 → UI を YouTube 準拠に揃える必要
2. **字幕ソース問題**: 自動生成字幕の精度／著作権 → まず NihongoHub 自家コンテンツ（47 都道府県動画ナレーション）で開始するのが安全
3. **モバイル必須度**: シャドーイングはスマホ需要が高い → Web First で開発 → PWA 化前提
4. **既存競合 (Migaku, LingQ, Language Reactor, Speechling)**: 差別化は「47 都道府県コンテンツ × 旅行文脈」「子連れ Ikimono Hakase Family ペルソナ」
5. **インタビュー n=1 の検証必要**: Discord β tester（PR-18）で 5-10 名に同じニーズがあるか確認してから PR 起票推奨
