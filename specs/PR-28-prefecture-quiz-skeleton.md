# PR-28: 都道府県別クイズ（媒体発見 → 一次ソース遡及方式）スケルトン

- **起票日**: 2026-05-21
- **親決定**: `notes/2026-05-21-decisions.md` 決定 1
- **位置づけ**: PR-25 Japan Life Quiz の history_geo を県別に深化させた**コンテンツ生成エンジン**。JLPT クイズ（コア）と併存する付加価値レイヤ。
- **優先度**: 中（年度優先度 4 位、Phase C1〔〜6/15〕後の着手が現実的）
- **状態**: skeleton（実装前）

## 目的（Goal-Driven Execution）

「NHK・民放・ネットが取り上げた県の話題を**面白さの発見シグナル**として使い、その**事実を一次ソースに遡及して出典明記でクイズ化**する。日本人にもためになり、かつ著作権上クリーンな県別クイズを、効率よく量産できるパイプライン」を作る。

## スコープ（Surgical: ここまで）

### 1. 5 ステップ・パイプライン

| # | ステップ | 入力 | 出力 | 既存資産 |
|---|---|---|---|---|
| 1 | 発見 | 媒体（NHK/民放/ネット）の県話題 | 面白さシグナル候補リスト | Japan Content Stock（daily/weekly/monthly） |
| 2 | 事実抽出 | 話題 | 核となる"事実"（数値・出来事・地理） | LLM 抽出 |
| 3 | 一次ソース遡及 | 事実 | 一次ソース URL + 裏取り値 | `data-source-whitelist-prefecture-quiz.md` |
| 4 | クイズ化 | 一次ソース | 4 択クイズ（やさしい日本語 + 多言語解説 + 出典） | PR-25 buildLifeQuizPrompt 拡張 |
| 5 | 検証 | クイズ | 合否 | PR-11 grep + LLM-judge（出典欠落 / 媒体出典化チェック追加） |

### 2. 2 レイヤ設計（ターゲット両立）

- **学習者レイヤ**: やさしい日本語 + 5 言語解説（N5–N1 レベル別）。コア顧客（海外学習者）向け。
- **一次情報レイヤ**: 日本人も唸る正確な数字・出典。差別化と「ためになる」訴求。
- 1 問の中で両立（問題文＝やさしい / 解説＝一次情報 + 出典）。

### 3. データソース

→ `data-source-whitelist-prefecture-quiz.md` を参照（実装時はこのホワイトリストを import）。
**NHK 素材は使わない**（発見シグナルのみ）。e-Stat / RESAS / 自治体オープンデータ / ジャパンサーチ / NDL PD が材料。

### 4. ガードレール（PR-11 継承 + 追加）

- 出典 URL 必須 / 一次ソース遡及不可ならドロップ / CC BY は著作者表示 / 編集著作権回避（番組構成の 1:1 再現禁止）/ 媒体名を出典にしない。
- アフィリ動線一元化（MK-16）/ 行政書士法配慮（権利義務文書化しない）を継承。

## 確証バイアス潰し（決定ノートより要約）

- 死角: 一次ソース遡及不可時のパラフレーズ流用（禁止）/ 編集著作権 / 媒体バイアス（観光地偏重）→ e-Stat 逆引き生成を少量混ぜる。
- 効率: アイデア出し激減（痛点解消）、遡及の手間は増えるが差し引きプラス、半自動化可。
